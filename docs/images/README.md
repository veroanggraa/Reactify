# Demo assets

Screen recordings referenced from the main README and the docs site. Record these from the
sample app — `app` for Android, `iosApp` for iOS — and drop them in here with these exact names:

| Feature | Android | iOS |
| --- | --- | --- |
| Transfer | `transfer-android.gif` | `transfer-ios.gif` |
| Bottom Navigation Indicator | `nav-indicator-android.gif` | `nav-indicator-ios.gif` |
| Segmented Control | `segmented-control-android.gif` | `segmented-control-ios.gif` |

Keep them short (a few seconds, looping) and under a few MB each.
